# Bastion

Jeu de stratégie militaire sur navigateur (base, champs, troupes, Titan, carte du monde 750×750), inspiré de Dragons of Atlantis.

- `index.html` : la page du jeu
- `css/style.css` : l'interface
- `js/game.js` : toute la logique du jeu
- `assets/img/` : les images (générées avec Gemini)
- `assets/fonts/` : les polices

Jouer : activer GitHub Pages (Settings → Pages → branche `main`) puis ouvrir https://spadeure.github.io/Bastion/
